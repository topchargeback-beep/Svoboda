# #БольшеСвободы — школа предпринимательских навыков

Сайт школы предпринимательских навыков **#БольшеСвободы**. Проект помогает действующим предпринимателям развивать навыки коммерческого роста, управления, делегирования, системности и создания новой ценности через практику в собственном бизнесе.

**Главная идея:** предпринимательство — это профессия. Бизнес растёт до уровня навыков предпринимателя. Школа развивает предпринимательские навыки через практику в действующем бизнесе: каждую неделю — инструмент → внедрение → обратная связь → навык.

## Стек

Чистый статический сайт без сборки и зависимостей: HTML + CSS + ванильный JavaScript.

- мгновенная загрузка, SEO «из коробки»;
- хостинг где угодно (GitHub Pages, Vercel, Netlify);
- тексты редактируются прямо в HTML-файлах.

## Как запустить локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Что нужно настроить перед запуском

### 1. Приём заявок (Яндекс Форма)

Все заявки принимаются через встроенную **Яндекс Форму** — никаких сторонних обработчиков и имитации успешной отправки нет.

- На `razbor.html` и `contacts.html` форма встроена напрямую через `<iframe>` (`https://forms.yandex.ru/u/6a36a2ab49af472e2b887cac?iframe=1`) + скрипт `https://forms.yandex.ru/_static/embed.js`.
- На остальных страницах кнопки «Пройти диагностику» / «Подобрать программу» открывают ту же форму в модальном окне (атрибут `data-open-diagnostics-modal`, ленивая загрузка iframe).

Чтобы подключить другую форму, замените ссылку Яндекс Формы в `<iframe>` и в контейнере модального окна. Запасной канал связи — личный Telegram и MAX рядом с формой.

### 2. Ссылки и контакты — централизованы

Все соцсети и контакты заданы один раз в `SITE_LINKS` (`js/main.js`) и подставляются во все элементы с атрибутом `data-link`:

```js
var SITE_LINKS = {
  telegram:  "https://t.me/insarvv",
  youtube:   "https://youtube.com/@insarvv",
  vk:        "https://vk.com/bolshe__deneg",
  instagram: "https://www.instagram.com/vvinsar",
  podcasts:  "https://insarvv.mave.digital",
  max:       "https://max.ru/u/...",
  email:     "mailto:bolshedeneg1@mail.ru",
  phone:     "tel:+79673759955"
};
```

Внешние ссылки автоматически получают `target="_blank"` и `rel="noopener noreferrer"`.

### 3. Видеоотзывы в кейсах

Кнопка «Смотреть видеоотзыв» скрыта, пока в `VIDEO_LINKS` (`js/main.js`) не указана ссылка (поддерживаются YouTube и Kinescope).

### 4. Домен для SEO

После публикации замените домен в `sitemap.xml` и `robots.txt`.

## Как редактировать тексты

Все тексты лежат прямо в HTML-страницах, секции подписаны комментариями. Цвета и типографика — в CSS-переменных `:root` в начале `css/style.css`.
