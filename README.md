# СВОБОДА — школа предпринимательства

Многостраничный сайт школы предпринимательства «СВОБОДА».

**Главная идея:** предпринимательство — это профессия. Бизнес растет только до уровня развития предпринимателя.

## Стек

Чистый статический сайт без сборки и зависимостей: HTML + CSS + ванильный JavaScript.

- мгновенная загрузка, SEO «из коробки»;
- хостинг где угодно (GitHub Pages, Vercel, Netlify, любой статический хостинг);
- тексты редактируются прямо в HTML-файлах.

## Как запустить локально

Достаточно открыть `index.html` в браузере, либо поднять локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Что нужно настроить перед запуском

### 1. Отправка заявок (формы)

Сейчас работает заглушка: форма показывает экран успеха, заявка логируется в консоль браузера.

Откройте `js/main.js` и заполните `FORM_CONFIG`:

```js
var FORM_CONFIG = {
  telegramBotToken: "123456:ABC-DEF...", // токен бота от @BotFather
  telegramChatId: "-1001234567890",      // id чата/канала для заявок
  webhookUrl: ""                          // или произвольный webhook (CRM, n8n, Make)
};
```

Можно использовать Telegram, webhook или оба канала сразу. Webhook получает заявку POST-запросом в формате JSON — это позволяет подключить любую CRM или email-сервис.

> Важно: токен Telegram-бота в клиентском коде виден всем. Для продакшена лучше указать `webhookUrl` на свой бэкенд/n8n/Make, который уже сам отправит сообщение в Telegram.

### 2. Ссылки Telegram и YouTube

В `js/main.js` заполните `SOCIAL_LINKS` — ссылки автоматически подставятся во все кнопки сайта:

```js
var SOCIAL_LINKS = {
  telegram: "https://t.me/...",
  youtube: "https://youtube.com/@..."
};
```

### 3. Видеоотзывы в кейсах

В каждой карточке кейса свёрстана кнопка «Смотреть видеоотзыв» — она скрыта, пока не указана ссылка. Заполните `VIDEO_LINKS` в `js/main.js` ссылками на видеоотзывы из проектов Большеденег:

```js
var VIDEO_LINKS = {
  "ramil": "https://youtube.com/watch?v=...",
  "kst": "",
  ...
};
```

### 4. Живые фотографии

Подготовлены места под реальные фото (встречи, выступления, стратегические сессии — материалы с сайта Большеденег):

- **Фото Инсара** — блоки `.founder-photo` на главной (манифест «Почему я создаю СВОБОДУ») и на странице «О школе». Положите `assets/insar.jpg` и добавьте внутрь блока `<img src="assets/insar.jpg" alt="Инсар Валиахметов">` — место помечено комментарием. Подпись с именем поверх фото уже свёрстана.
- **Фотолента «Школа вживую»** на главной — 4 карточки `.photo-card`. Добавьте внутрь каждой `<img src="assets/photo-1.jpg" alt="...">` — подпись и затемнение уже свёрстаны.
- **Фото клиентов в кейсах** — сейчас аватары с инициалами (`.case-avatar`). Чтобы поставить фото, замените аватар на `<img class="case-photo" src="assets/case-ramil.jpg" alt="Имя">`.

### 5. Домен для SEO

После публикации замените `example.com` на реальный домен в `sitemap.xml` и `robots.txt`.

### 6. Тексты-заглушки в кейсах

Результаты, внедрения и навыки в кейсах взяты из ТЗ. Блоки «Что было на старте», цитаты клиентов и кейс «Патентное бюро „Другое дело“» написаны как черновик — проверьте и замените на реальные формулировки клиентов.

## Как редактировать тексты

Все тексты лежат прямо в HTML-страницах, секции подписаны комментариями (`<!-- Блок 4. Цикл обучения -->`). Стили менять не нужно — достаточно заменить текст между тегами.

Цвета и типографика настраиваются в начале `css/style.css` (CSS-переменные `:root`).
