# #БольшеСвободы — школа предпринимательства

Многостраничный сайт школы предпринимательства **#БольшеСвободы**.

**Главная идея:** предпринимательство — это профессия. Бизнес растёт только до уровня развития предпринимателя. Школа развивает предпринимательские навыки через практику в действующем бизнесе: каждую неделю — инструмент → внедрение → обратная связь → навык.

## Стек

Чистый статический сайт без сборки и зависимостей: HTML + CSS + ванильный JavaScript.

- мгновенная загрузка, SEO «из коробки»;
- хостинг где угодно (GitHub Pages, Vercel, Netlify);
- тексты редактируются прямо в HTML-файлах.

## Как запустить локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Что нужно настроить перед запуском

### 1. Приём заявок (формы) — обязательно

По умолчанию обработчик не подключён, и форма **не имитирует** успешную отправку: при сабмите она готовит текст заявки и предлагает отправить его в Telegram или MAX (честный fallback).

Чтобы заявки уходили автоматически, откройте `js/main.js` и заполните `FORM_CONFIG`:

```js
var FORM_CONFIG = {
  telegramBotToken: "123456:ABC-DEF...", // токен бота от @BotFather
  telegramChatId: "-1001234567890",      // id чата/канала для заявок
  webhookUrl: ""                          // или произвольный webhook (CRM, Formspree, Getform, n8n, Make)
};
```

После заполнения форма отправляет заявку и показывает «Заявка отправлена» только при успешном ответе. Fallback на Telegram/MAX остаётся запасным каналом при ошибке.

> Токен Telegram-бота в клиентском коде виден всем. Для продакшена лучше указать `webhookUrl` на свой бэкенд/serverless, который сам отправит сообщение в Telegram.

### 2. Ссылки и контакты — централизованы

Все соцсети и контакты заданы один раз в `SITE_LINKS` (`js/main.js`) и подставляются во все элементы с атрибутом `data-link`:

```js
var SITE_LINKS = {
  telegram:  "https://t.me/insarvv",
  youtube:   "https://youtube.com/@insarvv",
  vk:        "https://vk.com/bolshe__deneg",
  instagram: "https://www.instagram.com/vvinsar",
  podcasts:  "https://insarvv.mave.digital",
  max:       "https://max.ru/u/...",
  email:     "mailto:bolshedeneg1@mail.ru",
  phone:     "tel:+79673759955"
};
```

Внешние ссылки автоматически получают `target="_blank"` и `rel="noopener noreferrer"`.

### 3. Видеоотзывы в кейсах

Кнопка «Смотреть видеоотзыв» скрыта, пока в `VIDEO_LINKS` (`js/main.js`) не указана ссылка (поддерживаются YouTube и Kinescope).

### 4. Домен для SEO

После публикации замените домен в `sitemap.xml` и `robots.txt`.

## Как редактировать тексты

Все тексты лежат прямо в HTML-страницах, секции подписаны комментариями. Цвета и типографика — в CSS-переменных `:root` в начале `css/style.css`.
